# golden_tree

golden_tree 是一个为**手动执行**设计的纳斯达克 100（QQQ）趋势跟踪策略：牛市时用适度杠杆（最高 1.5 倍，杠杆部分用 2 倍 ETF QLD），熊市时降仓、空仓或小比例做空（PSQ），不投资的钱放短期国债 ETF（SGOV）。

- **目标**：长期收益高于一直持有 QQQ，同时最大回撤不深于一直持有 QQQ。
- **好执行**：规则全部机械化，加仓每周最多检查一次，平均每年约 7 次下单；只用普通 ETF，不需要融资或期权账户。
- **工程内容**：策略本身，两个对照方案（一次性全仓买入 QQQ、每月定投 QQQ），行情下载，以及对比图。
- **日常使用**：每个交易日收盘后运行两条命令（更新行情、查看今日信号），需要调仓时在下一个交易日开盘手动下单。
- **实现**：只用 Python 标准库，没有第三方依赖，在 WSL（Ubuntu）的虚拟环境 `.venv` 中运行。

> 以下结果均为历史回测，不代表未来收益，也不构成投资建议。

## 策略规则

每天收盘后计算信号，**下一个交易日开盘**执行。

### 1. 判断牛市还是熊市：三票投票，至少两票判为牛市才算牛市

| 投票 | 判为牛市的条件 |
| --- | --- |
| 200 日均线带 | 收盘价高于 200 日均线 1% 以上时转为牛市，低于 2% 以上时转为熊市，介于两者之间时维持原判断 |
| 10 个月均线（Faber） | 最近一个月末收盘价高于最近 10 个月末收盘价的平均值 |
| 12 个月动量 | 过去 252 个交易日的涨幅高于同期短期国债收益 |

### 2. 决定 QQQ 仓位

- **牛市**：仓位 = 35% ÷ 近 20 日年化波动率，取最接近的 0.5 / 1 / 1.5 倍，最高 1.5 倍。
  按当前公式：20 日波动不超过约 28% 时为 1.5 倍，28%–47% 时为 1 倍，更高时为 0.5 倍。
- **熊市**：
  - MA7 高于 MA25，或 MTUM 近 20 日涨幅超过 USMV：持有 0.5 倍；
  - 否则如果 200 日均线比 20 个交易日前更低：做空 0.5 倍（买 PSQ）；
  - 否则空仓。
- **闲置资金**：不在 QQQ / QLD / PSQ 里的资金，全部买短期国债 ETF（SGOV）。
- **贪婪恐惧指数**：`today` 会显示 CNN 贪婪恐惧指数，只作参考，不参与决策。2011 年以来的检验显示，它能提示接下来波动变大，但不能预测涨跌方向；“熊市里极度恐惧就抄底”在 2011 年后有效，在 2000–2002、2008 年的长熊市里会大幅加深回撤。

### 3. 何时操作

- **加仓**只在每周最后一个交易日检查。
- **减仓**每天都检查，出现就执行。
- 历史上平均每年约 7 个交易日需要下单。

### 4. 对应的实际持仓（全部是普通 ETF，不需要融资）

| QQQ 仓位 | 实际持仓 |
| --- | --- |
| 1.5 倍 | 50% QQQ + 50% QLD |
| 1 倍 | 100% QQQ |
| 0.5 倍 | 50% QQQ + 50% SGOV |
| 0 | 100% SGOV |
| -0.5 倍 | 50% PSQ + 50% SGOV |

## 回测结果（数据截至 2026-10-14 收盘）

| 时期 | 策略年化 / 最大回撤 | 满仓持有 QQQ 年化 / 最大回撤 |
| --- | --- | --- |
| 2020–2026 | 26.0% / -27.5% | 20.5% / -35.1% |
| 2005–2019 | 12.5% / -35.1% | 12.7% / -53.4% |
| 2000–2004 | 10.2% / -25.6% | -16.0% / -83.0% |
| 2000–2026 | 15.4% / -35.1% | 8.6% / -83.0% |
| 最近 12 个月 | +28.1% / -18.8% | +23.0% / -12.0% |

| 投入方式（2020-01 起） | 策略 | QQQ |
| --- | --- | --- |
| 一次性投入 1 万美元 | 约 4.8 万 | 约 3.5 万 |
| 每月定投 1000 美元（共 8.2 万） | 约 20.0 万（年化 26.1%） | 约 16.5 万（年化 20.6%） |

**回测口径**：

- 交易成本按成交额的 0.05% 计算；闲置现金按 13 周国债收益率计息。
- 杠杆部分按 QLD 的实测成本计算，即国债利率 + 2%/年；做空部分按 PSQ 计算，费率 0.95%/年。
- 不计税。

**局限**：

- 策略的参数是在 2020 年以后的数据上反复比较、挑选出来的，属于样本内结果，未来表现很可能打折扣。
- 急跌或阴跌初期波动率不高，策略可能正处在 1.5 倍杠杆，跌幅会被放大；V 型反弹时还会在接近底部时减仓、反弹后才加回。
- 按随机重抽历史估计（与 2020 年至今同样长度的 2000 条路径）：年化中位约 15%，差情形约 1.5%，好情形约 32%；最大回撤中位约 -32%，差情形约 -49%；收益和回撤同时跑赢 QQQ 的概率约 67%。
- 杠杆上限原为 2 倍，2026-10 降为 1.5 倍：2020 年以来年化少约 4 个百分点，但各时期最大回撤都更浅，交易次数也减半。
- 手动执行时，一旦漏掉减仓信号，可能承受远超回测的回撤（QLD 本身历史最大回撤超过 -60%）。

## 代码结构

```text
quant/
  fetch_data.py   从 Yahoo Finance 下载 QQQ、MTUM、USMV、^IRX 日线到 data/；另下载 CNN 贪婪恐惧指数
                  （来自公开的每日归档 github.com/whit3rabbit/fear-greed-data，仅用于显示）
  core.py         数据对齐、均线和波动率、回测引擎、收益指标
  strategy.py     三票投票策略：信号、目标仓位、实际持仓、每日操作提示
  lump_sum.py     一次性全仓：期初 1 万美元全部买入 QQQ，与策略对比
  dca.py          每月定投：每月第一个交易日投入 1000 美元，与策略对比
  plot.py         生成对比图 reports/comparison_<起始年>.svg
data/             行情数据（CSV，由 fetch_data.py 下载，不纳入 git）
reports/          生成的图表（由 plot.py 生成，不纳入 git）
```

## 环境准备

开发环境是 WSL 里的 Ubuntu 22.04，使用系统自带的 Python 3.10.12。工程没有第三方依赖，只用标准库（`csv`、`json`、`math`、`statistics`、`urllib` 等），所以虚拟环境里不需要 pip：

```sh
cd ~/workbench/golden_tree
python3 -m venv --without-pip .venv   # 创建虚拟环境，无需安装任何包
.venv/bin/python --version            # 确认版本：Python 3.10 或更高
```

- 加 `--without-pip`，是因为 Ubuntu 默认没有安装 `python3-venv`，不加会报 ensurepip 错误。以后如果需要 pip，先运行 `sudo apt install python3-venv`，再去掉这个参数重新创建。
- 需要能访问 `query2.finance.yahoo.com`（行情）和 `raw.githubusercontent.com`（贪婪恐惧指数）。
- `data/` 和 `reports/` 不在 git 里。新克隆的仓库要先运行一次 `fetch_data.py` 下载数据，再运行其他脚本。

## 运行方法

在 WSL 中进入工程目录：

```sh
cd ~/workbench/golden_tree

# 1. 更新行情（每天收盘后运行）
.venv/bin/python quant/fetch_data.py

# 2. 查看今天该持有什么、是否需要操作
.venv/bin/python quant/strategy.py today

# 3. 回测
.venv/bin/python quant/strategy.py                 # 各时期年化与最大回撤
.venv/bin/python quant/lump_sum.py                 # 一次性全仓对比，默认 2020-01-02 起
.venv/bin/python quant/lump_sum.py 2000-01-03      # 指定起始日期（也可以再加结束日期）
.venv/bin/python quant/dca.py                      # 每月定投对比，默认 2020-01-02 起
.venv/bin/python quant/plot.py                     # 生成 reports/comparison_2000.svg
.venv/bin/python quant/plot.py 2020-01-02          # 生成 reports/comparison_2020.svg
```

`strategy.py today` 的输出示例：

```text
数据截至 2026-10-14；QQQ 收盘 728.95，200 日均线 672.65，20 日波动 16.8%

熊市信号：MA7>MA25 是，MTUM>USMV 否，200 日均线下行 否
目标持仓：50% QQQ + 50% QLD
操作：无需调整
贪婪恐惧指数（仅供参考，不参与决策）：32，恐惧（2026-10-14）
```
