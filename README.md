# golden_tree: 美股投资策略

golden_tree 是一个为**手动执行**设计的组合方案：一半资金放纳斯达克 100（QQQ），另一半放个股——伯克希尔（BRK-B）作为防守核心，再加 AI 基础设施和 AI 成长个股。用 QQQ 的三票投票判断牛熊：牛市满配，熊市把 QQQ 和 AI 成长股换成短期国债 ETF。

- **目标**：长期收益接近或高于一直持有 QQQ，最大回撤明显更浅（历史上约为 QQQ 的六到七成）。
- **好执行**：不用杠杆、不做空；牛熊切换平均每年不到 3 次，固定比例每季度调整一次。
- **工程内容**：组合规则与每日信号、两个对照方案（一次性全仓买入 QQQ、每月定投 QQQ）、行情下载、对比图。
- **实现**：只用 Python 标准库，没有第三方依赖，在 WSL（Ubuntu）的虚拟环境 `.venv` 中运行。

> 以下结果均为历史回测，不代表未来收益，也不构成投资建议。

## 组合规则

每天收盘后计算信号，**下一个交易日开盘**执行。

### 1. 判断牛市还是熊市：三票投票，至少两票判为牛市才算牛市

| 投票 | 判为牛市的条件 |
| --- | --- |
| 200 日均线带 | QQQ 收盘价高于 200 日均线 1% 以上时转为牛市，低于 2% 以上时转为熊市，介于两者之间时维持原判断 |
| 10 个月均线（Faber） | 最近一个月末收盘价高于最近 10 个月末收盘价的平均值 |
| 12 个月动量 | 过去 252 个交易日的涨幅高于同期短期国债收益 |

### 2. 持仓（占总资产）

| 部分 | 占比 | 牛市 | 熊市 | 名单 |
| --- | --- | --- | --- | --- |
| QQQ | 50% | 持有 QQQ | 换成 SGOV | |
| 防守核心 | 20% | 一直持有 | 一直持有 | BRK-B |
| AI 基础设施 | 15% | 一直持有，等权（各 2.5%） | 一直持有 | PWR、ETN、HUBB、EQIX、DLR、CSCO |
| AI 成长股 | 15% | 等权（各约 1.7%） | 换成 SGOV | TSM、KLAC、LRCX、AMAT、ANET、VRT、DELL、CIEN、MRVL |

- 名单和比例都写在 `quant/strategy.py` 开头的常量里，修改后运行一次 `fetch_data.py` 即可。
- 选股原则：AI 基础设施选和 QQQ 关联较低、2022 年熊市抗跌的电力、电网、数据中心地产和网络设备；AI 成长股选不属于 QQQ 重仓（权重 1.5% 以上）、也不属于 BRK-B 前十大持仓的公司，单只不超过总资产 5%。
- **贪婪恐惧指数**：`today` 会显示 CNN 贪婪恐惧指数，只作参考，不参与决策。2011 年以来的检验显示，它能提示接下来波动变大，但不能预测涨跌方向。

### 3. 何时操作

- **转为牛市**（买入 QQQ 和 AI 成长股）只在每周最后一个交易日检查。
- **转为熊市**（卖出 QQQ 和 AI 成长股，换成 SGOV）每天都检查，出现就执行。
- 2005 年以来平均每年切换约 2.8 次，约 81% 的时间处于牛市持仓。
- **每季度第一个交易日**把各项持仓调回目标比例，`today` 会提示。

## 回测结果（数据截至 2026-10-27 收盘）

| 时期 | 组合年化 / 最大回撤 | 一直持有 QQQ 年化 / 最大回撤 |
| --- | --- | --- |
| 2020 年以来 | 22.9% / -24.4% | 20.2% / -35.1% |
| 2005–2019 | 10.9% / -30.9% | 12.7% / -53.4% |
| 2005 年以来 | 14.6% / -30.9% | 15.0% / -53.4% |
| 2022 年 | -5.2% / -11.8% | -32.9% / -34.8% |
| 2007-10 至 2009-03 | 区间 -19.2%，最大回撤 -30.9% | 区间 -40.7%，最大回撤 -53.4% |
| 2025 年关税冲击 | 区间 -12.6% | 区间 -22.7% |
| 最近 12 个月 | +20.3% / -11.2% | +16.0% / -12.0% |

| 投入方式（2020-01 起） | 组合 | QQQ |
| --- | --- | --- |
| 一次性投入 1 万美元 | 约 4.1 万 | 约 3.5 万 |
| 每月定投 1000 美元（共 8.2 万） | 约 18.7 万（年化 23.9%） | 约 16.4 万（年化 20.1%） |

随机重抽历史（2005 年以来的日收益按 63 天一段重抽，2000 条与 2020 年至今等长的路径）：年化中位约 14.5%，差情形约 5%，好情形约 24%；最大回撤中位约 -22%，差情形约 -33%；93% 的路径最大回撤比 QQQ 浅。

**回测口径**：

- 交易成本按成交额的 0.05% 计算；SGOV 部分按 13 周国债收益率计息；不计税。
- 回测假设固定比例每天维持不变，实际每季度调一次，结果会有小幅差异。
- 上市较晚的股票（DLR 2004 年、ANET 2014 年、DELL 2016 年、VRT 2018 年）上市前不计入，其份额由同组其他股票平分。

**局限**：

- **个股名单有后视偏差**：名单是 2026 年 10 月按"AI 产业链、过去表现"挑出来的，2020 年以前的回测并不是这些公司的真实样本外表现，未来收益很可能低于回测。
- 2005–2019 年组合年化低于 QQQ：没有杠杆，熊市卖出后反弹初期会少赚。组合的优势主要是回撤更浅。
- BRK-B 不跟随信号卖出，它在 2008 年下跌约 48%，在 2020 年 3 月下跌约 29%，全面恐慌时挡不住下跌。
- 单只个股可能出现远超指数的跌幅（例如 MRVL 历史最大回撤约 -92%），所以每只仓位要小。
- 三票投票需要 QQQ 跌约 5%–10% 后才会转熊，V 型急跌时可能在接近底部卖出、反弹后才买回。

## 代码结构

```text
quant/
  fetch_data.py   从 Yahoo Finance 下载 QQQ、^IRX 和组合个股的日线到 data/；另下载 CNN 贪婪恐惧指数
                  （来自公开的每日归档 github.com/whit3rabbit/fear-greed-data，仅用于显示）
  core.py         数据对齐、均线、回测引擎、收益指标
  strategy.py     组合规则：持仓名单与比例、三票投票、牛熊切换、每日操作提示
  lump_sum.py     一次性全仓：期初 1 万美元全部买入 QQQ，与组合对比
  dca.py          每月定投：每月第一个交易日投入 1000 美元，与组合对比
  plot.py         生成对比图 reports/comparison_<起始年>.svg
data/             行情数据（CSV，由 fetch_data.py 下载，不纳入 git）
reports/          生成的图表（由 plot.py 生成，不纳入 git）
research/         本地研究数据、筛选和分析脚本、旧历史备份（不纳入 git）
```

## 环境准备

开发环境是 WSL 里的 Ubuntu 22.04，使用系统自带的 Python 3.10.12。工程没有第三方依赖，只用标准库（`csv`、`json`、`math`、`statistics`、`urllib` 等），所以虚拟环境里不需要 pip：

```sh
cd ~/workbench/golden_tree
python3 -m venv --without-pip .venv   # 创建虚拟环境，无需安装任何包
.venv/bin/python --version            # 确认版本：Python 3.10 或更高
```

- 加 `--without-pip`，是因为 Ubuntu 默认没有安装 `python3-venv`，不加会报 ensurepip 错误。以后如果需要 pip，先运行 `sudo apt install python3-venv`，再去掉这个参数重新创建。
- 需要能访问 `query2.finance.yahoo.com`（行情）和 `raw.githubusercontent.com`（贪婪恐惧指数）。
- `data/` 和 `reports/` 不在 git 里。新克隆的仓库要先运行一次 `fetch_data.py` 下载数据，再运行其他脚本。

## 运行方法

在 WSL 中进入工程目录：

```sh
cd ~/workbench/golden_tree

# 1. 更新行情（每天收盘后运行）
.venv/bin/python quant/fetch_data.py

# 2. 查看今天该持有什么、是否需要操作
.venv/bin/python quant/strategy.py today

# 3. 回测
.venv/bin/python quant/strategy.py                 # 各时期年化与最大回撤
.venv/bin/python quant/lump_sum.py                 # 一次性全仓对比，默认 2020-01-02 起
.venv/bin/python quant/lump_sum.py 2005-01-03      # 指定起始日期（也可以再加结束日期）
.venv/bin/python quant/dca.py                      # 每月定投对比，默认 2020-01-02 起
.venv/bin/python quant/plot.py 2005-01-03          # 生成 reports/comparison_2005.svg
.venv/bin/python quant/plot.py 2020-01-02          # 生成 reports/comparison_2020.svg
```

`strategy.py today` 的输出示例：
